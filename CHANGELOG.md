# История версий — Finance Budget

Все значимые изменения документируются в этом файле.  
Формат основан на [Keep a Changelog](https://keepachangelog.com/).  
Версионирование — [Semantic Versioning](https://semver.org/lang/ru/).

> ⚠️ **Примечание:** Все версии `0.x.y` являются нестабильными и предназначены только для внутренней разработки.

---

## [v0.7.4] - 2026-07-09

### Добавлено
- Реализован `CreditCardDialog` для управления кредитными картами с отдельным окном конфигурации параметров.
- Логика миграций базы данных вынесена в изолированный модуль `core/migration.py`.
- Внедрена проверка на связанные транзакции при операциях со счетами.

### Изменено
- **Рефакторинг модели `Account`:** Поля, специфичные для кредитных карт, удалены из общей таблицы счетов. Параметры кредиток теперь вынесены в отдельный диалог, в интерфейсе управления счетами оставлена только навигационная подсказка.
- Обновлена логика инициализации и открытия диалога добавления платежа (`AddPaymentDialog`).

### Исправлено
- Устранена ошибка, при которой кредитные карты не подгружались при инициализации `CreditCardDialog`.
- Реализован временный обход ограничения `FOREIGN KEY constraint failed` на уровне UI: теперь система требует явно удалять запись из таблицы `credit_cards` через специализированный диалог перед удалением самого счёта. *(Полное решение на уровне СУБД запланировано в следующих версиях)*

## [v0.6.4] - 2026-06-23

### Добавлено
- Диалог редактирования займов.
- Диалог для внесения платежей по займам.
- Диалог просмотра детальной информации по выбранному займу.

### Изменено
- Улучшена интеграция диалогов управления займами с главным окном приложения.
- Доработана логика обработки платежей для стабильной работы с текущей структурой базы данных.

---

## [v0.6.1] - 2026-06-23

### Добавлено
- **Диалог займов:** Реализован новый диалог для работы с займами.
- **Диалог добавления нового займа:**  Реализован новый диалог с проверкой вводимых данных и модальным режимом работы.
- Автоматическое обновление балансов счетов при внесении платежей по займам.
- Миграция базы данных для обеспечения обратной совместимости с данными предыдущей версии (V2).

### Изменено
- Логика статусов займов приведена в соответствие с архитектурой V3.
- Обработка платежей по займам теперь осуществляется через механизм внутренних переводов.

### Исправлено
- Устранены ошибки валидации и структуры полей модели займов.

## [v0.5.1] - 2026-05-10

### Изменено
- Улучшена логика работы диалога переводов: после успешного добавления перевода поля суммы и описания автоматически очищаются, остальные данные сохраняются для быстрого ввода следующего операции.
- Обновлено отображение таблицы переводов для лучшей читаемости данных.

### Исправлено
- Исправлена логика добавления внешних переводов (трансферов между счетами), устранены ошибки при сохранении.

---

## [v0.5.0] - 2026-05-10

### Добавлено
- **Диалог переводов:** Реализован новый диалог для работы с переводами внешними и внутренеми.
- **Диалог категорий:**
- Древовидное отображение категорий с поддержкой иерархии до 3 уровней вложенности.
- Контекстное меню для быстрого доступа к действиям.
- Защита от удаления категорий: система запрашивает подтверждение и блокирует удаление, если категория используется в транзакциях.
- Сквозная валидация данных во всех окнах приложения: проверка корректности ввода и вывод понятных сообщений об ошибках.

---

## [v0.4.0] - 2026-05-10

### Добавлено
- **Базовая архитектура диалогов:** Внедрен единый базовый класс `BaseDialog` со статус-баром, который теперь используется во всех окнах приложения для единообразия интерфейса.
- **Диалог управление категориями:** Реализован новый диалог для работы с категориями расходов и доходов.
  - Поддержка ввода названий категорий на русском языке.
  - Возможность активации и деактивации категорий без их удаления.
  - Валидация ввода данных: проверка корректности форматов бюджета и начального баланса.

### Изменено
- Рефакторинг иерархии классов интерфейса: все существующие диалоги переведены на наследование от `BaseDialog`.
