# Структура проекта

Финансовое приложение с использованием паттерна MVP (Model-View-Presenter).

## Дерево проекта

```
.
├── core/                      # Ядро приложения: модели, БД, репозитории
├── services/                  # Бизнес-логика и сервисы
├── ui/                        # Пользовательский интерфейс (Qt)
├── utils/                     # Утилиты и вспомогательные функции
├── main.py                    # Точка входа приложения
├── config.py                  # Конфигурация приложения
├── requirements.txt           # Зависимости Python
├── CHANGELOG.md               # История изменений
├── Задачи.txt                 # Список задач проекта
└── Черновик.txt               # Черновые заметки
```

---

## Детальное описание

### `core/` — Ядро приложения
Базовая инфраструктура и работа с данными.

```
core/
├── __init__.py
├── db.py                      # Подключение и настройка базы данных
├── models.py                  # SQLAlchemy модели (таблицы БД)
└── repositories/              # Репозитории для доступа к данным
    ├── __init__.py
    ├── base.py                # Базовый класс репозитория
    ├── accounts.py            # Репозиторий счетов
    └── transaction_repository.py  # Репозиторий транзакций
```

**Описание:**
- **`db.py`** — инициализация подключения к SQLite, создание сессий ORM
- **`models.py`** — определения таблиц `Account` и `Transaction`
- **`repositories/`** — слой доступа к данным, инкапсуляция SQL-запросов

---

### `services/` — Бизнес-логика
Сервисы высокого уровня для работы с финансовыми операциями.

```
services/
├── __init__.py
├── finance_service.py         # Логика управления счетами и финансами
└── transaction_service.py     # Логика работы с транзакциями
```

**Описание:**
- **`finance_service.py`** — создание/удаление счетов, получение баланса
- **`transaction_service.py`** — создание транзакций, валидация, списание/пополнение

---

### `ui/` — Пользовательский интерфейс
Qt-интерфейс с архитектурой MVP (Model-View-Presenter).

```
ui/
├── __init__.py
├── main_window.py             # Главное окно приложения
├── dialogs/                   # Диалоговые окна
│   ├── __init__.py
│   └── operation_dialog.py    # Диалог добавления транзакции
└── presenters/                # Презентеры (логика представления)
    ├── __init__.py
    └── main_presenter.py      # Презентер главного окна
```

**Описание:**
- **`main_window.py`** — виджет главного окна с таблицами и кнопками
- **`dialogs/operation_dialog.py`** — модальное окно для ввода операции
- **`presenters/main_presenter.py`** — связка View и Model, обработка событий

---

### `utils/` — Утилиты
Вспомогательные функции и форматиры.

```
utils/
├── __init__.py
├── converters.py              # Конвертеры данных (модель ↔ UI)
├── formatters.py              # Форматирование валюты, дат
└── validators.py              # Валидация пользовательского ввода
```

**Описание:**
- **`converters.py`** — QAbstractTableModel, перевод данных в вид для Qt
- **`formatters.py`** — форматирование сумм (₽), дат (DD.MM.YYYY)
- **`validators.py`** — проверка чисел, дат, названий счетов

---

### Корневые файлы

| `main.py` | Точка входа, запуск QApplication |

## Архитектурные паттерны

1. **MVP (Model-View-Presenter)** — разделение UI и логики
2. **Repository Pattern** — репозитории для доступа к данным
3. **Service Layer** — бизнес-логика в отдельных сервисах
4. **Dependency Injection** — внедрение зависимостей через конструкторы
