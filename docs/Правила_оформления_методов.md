# 📋 Стандарт оформления новых методов

## 1. Импорты в начале файла
```python
import logging
import traceback

logger = logging.getLogger(__name__)
```

## 2. Шаблон метода
```python
def method_name(self, params):
    """Docstring."""
    try:
        # Бизнес-логика
        return self.repo.do_something(params)
        
    except ValueError as e:
        # Ожидаемые ошибки валидации
        logger.warning(f"[{self.__class__.__name__}] Валидация: {e}")
        raise
        
    except Exception as e:
        # Системные ошибки
        logger.error(f"[{self.__class__.__name__}] Ошибка: {e}", exc_info=True)
        raise
```

## 3. Правила

| Что | Как |
|-----|-----|
| **Логгер** | `logger = logging.getLogger(__name__)` |
| **Валидация** | `logger.warning(...)` + `raise` |
| **Ошибки** | `logger.error(..., exc_info=True)` |
| **Инфо** | `logger.info(...)` или `logger.debug(...)` |
| **Запрещено** | `print()`, `traceback.print_exc()` |
| **Цепочка** | `raise RuntimeError("msg") from e` |
| Docstring | IDE-совместимый формат (см. п. 4) |

## 4. Docstring (IDE-совместимые)
Все новые методы должны сопровождаться IDE-совместимыми docstring. Поддерживаются два формата:

**Короткий формат (без аргументов):**
```python
"""Открывает управление категориями."""
```

**Полный формат (с описанием аргументов):**
```python
"""
Инициализация диалога.

Args:
    parent: родительское окно 
    presenter: экземпляр AccountPresenter, внедрённый из родительского окна

Returns:
    Целое число int или None, если строка пустая
    
Raises:
    ValueError: если строка не является корректным целым числом
"""
```

## 5. В UI (Dialogs)
```python
try:
    self.presenter.action()
except ValueError as e:
    self.show_status(str(e), "error")  # Показываем пользователю
except Exception as e:
    logger.error(f"Ошибка UI: {e}", exc_info=True)
    self.show_status("Произошла ошибка", "error")
```

## ⚠️ Единственное исключение

**Специфичные методы** (retry-логика, кастомные исключения, транзакции и т.п.) — требуют адаптации шаблона, а не механического применения.

**Пример:**
```python
# Метод с retry — НЕ подходит под стандартный шаблон
```
